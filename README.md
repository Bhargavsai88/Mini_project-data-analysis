# 🛍️ Customer Behavior Analysis

A complete end-to-end data analytics project analyzing customer shopping behavior.

## 🔧 Tools Used
- **Python** (Pandas, Matplotlib, Seaborn)
- **PostgreSQL** (Database storage & SQL queries)
- **Power BI** (Interactive dashboard)
- **VS Code** (Development environment)
- **GitHub Pages** (Deployment)

## 📊 Project Overview
Analyzed 3,900 customer records to uncover shopping patterns, revenue trends, and customer segments.

## 🔍 Key Insights
- 📦 Clothing is the top revenue-generating category
- 💳 74% of customers are non-subscribers
- 🚚 Standard shipping is most preferred
- ⭐ Average review rating: 3.77
